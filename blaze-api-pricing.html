API console billing copy (app.blaze.vn, published 16 Oct 2026)

These lines come from the public locale files used by the signed-in API console. They describe how billing works; they do not list package prices.

  • Credit rate: “1.000 credits = 1 USD” (English: “1,000 credits = $1”), with an approximate VND amount filled in by the app. Source: https://app.blaze.vn/locales/vi/api.json and https://app.blaze.vn/locales/en/api.json
  • Credits: “Credits dùng chung cho mọi API và không hết hạn.” (English: “Credits work across every API and never expire.”) Source: https://app.blaze.vn/locales/vi/api.json and https://app.blaze.vn/locales/en/api.json
  • TTS billing: “Tính phí theo số token của văn bản bạn gửi lên.” (English: “Billed per token of the text you send.”) Source: https://app.blaze.vn/locales/vi/api.json and https://app.blaze.vn/locales/en/api.json
  • STT billing: “Tính phí theo số token của văn bản nhận dạng được. Thời lượng âm thanh không tính phí.” (English: “Billed per token of the transcribed text. Audio duration is free.”) Source: https://app.blaze.vn/locales/vi/api.json and https://app.blaze.vn/locales/en/api.json
  • Per-minute estimates: “Giá theo phút của TTS/STT là ước tính (khoảng 180 token mỗi phút nói); chi phí thực tế tính theo token.” (English: “TTS/STT per-minute prices are estimates (about 180 tokens per spoken minute); you're billed by tokens.”) Source: https://app.blaze.vn/locales/vi/api.json and https://app.blaze.vn/locales/en/api.json
  • Other groups: voice services “Tính phí theo lượt gọi hoặc thời lượng âm thanh.” (“Billed per request or per audio duration.”); language services “Tính phí theo số token xử lý.” (“Billed per processed token.”) Source: https://app.blaze.vn/locales/vi/api.json and https://app.blaze.vn/locales/en/api.json
  • Rate-limit tiers: “Giới hạn tăng theo tổng chi tiêu của tài khoản.” (English: “Rate limits grow with your account’s total spend.”) Tier thresholds are filled in by the app and are not published in the file. Source: https://app.blaze.vn/locales/vi/api.json and https://app.blaze.vn/locales/en/api.json
  • Payment: card top-ups through Stripe (“Giao dịch được xử lý an toàn bởi Stripe”), optional promo code, and optional auto top-up (“Tối đa {{count}} lần mỗi ngày. Nếu thẻ bị từ chối, nạp tự động sẽ tắt và chúng tôi gửi email cho bạn.”). The count is filled in by the app. Source: https://app.blaze.vn/locales/vi/api.json and https://app.blaze.vn/locales/en/api.json

Two published wordings, both kept: blaze.vn/pricing lists Speech to Text as “Price per minute” and Text to Speech “per 1M character” / “per hour”. The API console copy above says TTS and STT are billed per text token, STT audio duration is free, and per-minute figures are estimates at about 180 tokens per spoken minute.

  • The console usage view description changed from “Credits used by product, model and API key.” to “Credits used per API key.” Source: https://app.blaze.vn/locales/vi/api.json and https://app.blaze.vn/locales/en/api.json

Đã bao gồm phần dịch, dù dùng công cụ dịch nào.” (“Billed per second of audio you send, rounded up per session: $0.0025 per minute ($0.15 per hour of audio).”) A session with the voice on is “billed as its own credit line, separate from text only”, at the same $0.0025 per minute, translation and voice included.   • New LLM group: “Mô hình ngôn ngữ lớn (LLM)” — “Tính phí theo số token đầu vào và đầu ra.” (“Billed per input and output token.”) Model list note: “Giá tính bằng credit cho 1 triệu token · 1.000 credit = 1 USD” (“Prices in credits per 1M tokens · 1,000 credits = $1”). Per-model LLM prices are served by GET /v1/models and are not in the locale files. Source: https://app.blaze.vn/locales/vi/api.json and https://app.blaze.vn/locales/en/api.json
  • LLM API (replaces the former “Language Model (LLM) API” text-completions docs, whose /v1/llm/completions and /v1/llm/models paths were removed from the schema; new /v1/chat/completions, /v1/models): “Trò chuyện với các mô hình ngôn ngữ lớn hàng đầu qua một API tương thích OpenAI … Chi phí tính bằng API credit theo token đầu vào và đầu ra.” Billing rules as published: each request is charged “input tokens × input price + output tokens × output price”; a request needs a positive credit balance and, if the balance can’t cover the full output, the output is shortened (finish_reason “length”); streams are charged for what was generated even if you disconnect early; “Requests that fail (4xx, 5xx) are not charged.” (“Request lỗi (4xx, 5xx) không bị tính credit.”) Example model ID format: openai/gpt-5.4. Key path: widget.llmGateway.*. Source: https://app.blaze.vn/locales/vi/api.json and https://app.blaze.vn/locales/en/api.json; Source: https://api.blaze.vn/openapi.json

Source: https://app.blaze.vn/locales/vi/api.json and https://app.blaze.vn/locales/en/api.json
