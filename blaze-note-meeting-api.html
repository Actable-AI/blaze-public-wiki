Blaze Note Meeting API

Marketing page: “Meeting API — đưa AI họp vào sản phẩm của bạn.” “REST + WebSocket + webhooks để tạo phiên, stream transcript realtime, lấy tóm tắt/biên bản và đồng bộ sự kiện vào hệ thống của bạn.” Example call: POST /v1/meetings. “Xác thực bằng API key, scope theo tài nguyên — phù hợp tích hợp doanh nghiệp.” Source: https://note.blaze.vn/meeting-api

Developer docs (public HTML):

  • API host in the quickstart: https://note-api.blaze.vn
  • “Create an API key in the portal (Developer) on a Business plan or higher. Copy the secret once (sk_live_… / sk_test_…).”
  • Summary generation: “Generate a summary (1 credit)”
  • Smoke test: GET /v1/me

Source: https://note.blaze.vn/developer/docs/quickstart

Auth: Authorization: Bearer or X-API-Key. Prefixes sk_live_… (Production) and sk_test_… (Test). “Keys require the Business plan (or higher) with api_access; the plan is re-checked on every call.” “Rate limit: default 120 requests/minute per key (overridable). Over limit → 429 with Retry-After: 60.” Default scope *. Source: https://note.blaze.vn/developer/docs/conventions

Credits: “AI ops spend the same monthly credit budget as the app. Cost is 1 credit unless noted free. … Exhausted budget → 402.” Named 1-credit operations include POST /v1/meetings/{id}/chat, .../summary, .../reports, .../transcripts/translate (refunded if validation fails or cache hit), POST /v1/translate, POST /v1/summarize, POST /v1/refine, POST /v1/complete, POST /v1/tts. Meetings CRUD, ingest, transcript read/write/export, folders, participants, speakers, keywords fetch, recordings, webhooks are listed as free. Source: https://note.blaze.vn/developer/docs/conventions

Meeting resource fields published: id, session_id, room_code, title, session_type, status (waiting | active | paused | ended), languages, auto_translate, translate_mode (one_way in the example), speaker_mode (single). Source: https://note.blaze.vn/developer/docs/resources
